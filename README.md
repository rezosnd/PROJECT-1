# PROJECT-1

GetMyHospital — emergency health grid (web + mobile + API) for real-time hospital bed matching, ABHA/ABDM linkage, and hospital ops.

## Apps

- `apps/api` — Express API (Neon/Postgres, ABDM/Eka, Google auth)
- `apps/web` — Vite patient/hospital portal
- `apps/mobile` — Expo patient app

## Setup

Copy `.env.example` files in each app and fill secrets locally. Do **not** commit `.env` files.
